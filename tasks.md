## Review the model's translations

Goal: every translation the categorizer adds in real use can be exported for a person (the native speaker) to review, the same way the seed's twins are reviewed. To keep that possible with `same_as` alone, a model-made twin is always a link: the categorizer creates a twin only for an exact equivalent. A close-but-not-exact translation (`crema` for `sour cream`) creates nothing, so when someone types that word the model files it on its own terms instead of it inheriting the other name's aisle and unit unseen.

Then link it at once. When it isn't exact, or the link can't be made, create nothing; an existing twin is left as it is. The answer keeps its own `lang`, category and unit as today. The prompt doesn't change (it still asks for `translation` and `exact_equivalent`). Update the Deno tests that expect an unlinked twin, and add tests: not exact creates no row; exact but unlinkable creates no row; exact and linkable creates and links.
