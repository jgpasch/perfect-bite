## Item details: tap to open

Goal: tapping an item's name opens its details, and only the round check checks it off. Today the whole row toggles the check (`src/features/lists/item-row.tsx`) and the edit sheet (`src/app/list/[id]/item/[itemId].tsx`) opens only on a long-press nobody finds. These tasks change behaviour, so update `docs/spec.md` (4.2, 4.3.2, and anywhere else that says long-press or row-tap) in the same task as the code, and keep the Pantry look from DESIGN.md.

- [ ] Tap the name to open, tap the check to check. Drop the long-press, since a tap now does it. In selection mode (Make recipe / Add to recipe) a tap anywhere on the row still selects, as today. Swipe-to-delete stays. Do the same in By recipe view and anywhere else `ItemRow` is used. Accessibility: the check is a `checkbox` labelled "Check off <name>" with its checked state; the row body is a `button` with the current row label and the hint "Opens details"; keep the Edit / Delete custom actions on the row, and add a "Check off" / "Uncheck" one so VoiceOver users can do it without finding the circle. Check the pressed-state opacity only dims the part that was pressed. Add a test for any pure helper that changes (e.g. the labels). Manual check in the simulator: tapping a name never checks it, tapping the circle never opens the sheet, scrolling with a finger on a row does neither.
