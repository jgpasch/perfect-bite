# Future work

One file per feature, named `<feature>-tasks.md`. Ralph doesn't read this folder; it works only `tasks.md`.

Each file starts with a status line:

- **ready**: written as Ralph tasks (`- [ ] description`, one per iteration). Move the section into `tasks.md`, in order, to start it.
- **ideas**: plain bullets, not tasks yet. Write them up as tasks (and update `docs/spec.md`) before moving them into `tasks.md`.

Ideas too small or vague for their own file go in [wishlist.md](wishlist.md), one line each.

When a feature is fully moved into `tasks.md`, delete its file here. When you park work from `tasks.md`, move it into the matching file here (or a new one).
